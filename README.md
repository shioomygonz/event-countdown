# Event Countdown

Event Countdown is a simple web application that allows users to create a countdown for an event.

## Features

- Enter an event name
- Select the date and time of the event
- Start the countdown
- Display the remaining days, hours, minutes, and seconds
- Show a message when the event starts

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter the name of your event.
2. Select the event date and time.
3. Click **Start Countdown**.
4. The application will display the remaining time.
